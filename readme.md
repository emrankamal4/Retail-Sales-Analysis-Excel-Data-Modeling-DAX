# Retail Sales Analysis — Excel Data Modeling & DAX

An end-to-end retail sales analysis project built in **Microsoft Excel**, focusing on data modeling, DAX measures, KPI analysis, and interactive reporting.

## 📊 Project Overview

The project analyzes **3,000 sales transactions** across products, customers, regions, and dates. A relational data model was created to connect the sales fact table with supporting dimension tables.

The analysis focuses on sales performance, profitability, order activity, products, regions, and customer segments.

## 🛠️ Tools & Skills

* Microsoft Excel
* Data Modeling
* DAX Measures
* PivotTables & PivotCharts
* KPI Analysis
* Date/Calendar Dimension
* Relationships between fact and dimension tables
* Interactive Dashboard

## 🗂️ Data Model

The workbook uses a fact-and-dimension structure:

* **Sales** — transaction-level sales data
* **Products** — product, category, subcategory, and cost information
* **Customers** — customer and segment information
* **Regions** — regional information
* **Calendar** — date, year, month, and quarter attributes

## 📈 Key Metrics

The analysis includes:

* Total Sales
* Total Profit
* Profit Margin
* Total Orders
* Units Sold
* Average Order Value
* Total Cost
* Previous Year Sales

## 🔍 Analysis

The project examines:

* Sales by product and subcategory
* Sales by region
* Sales by customer segment
* Monthly sales performance
* Product performance across years
* Overall sales and profitability KPIs

## 📌 Key Result

The dataset generated approximately **$1.32M in total sales**, with approximately **$446K in total profit** and a **33.8% profit margin**.
